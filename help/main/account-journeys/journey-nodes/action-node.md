# Nœud Prendre une action

Utilisez les nœuds d’action dans [!DNL Adobe Journey Optimizer B2B Edition] pour définir des actions pour les comptes ou les personnes d’un parcours. Comparez les actions de compte et les actions de personnes, et découvrez les actions prises en charge par chaque type de parcours.

>[!VIDEO](https://video.tv.adobe.com/v/3443207/?quality=12&learn=on)

## Nœud d’action essentiel

La vidéo aborde les sujets suivants :

* Objectif des nœuds d’action dans un parcours.
* La différence entre les actions de compte et les actions de personnes.
* Prise en charge des actions pour tous les types de parcours.

## Documentation connexe

Pour les étapes de configuration et les actions de compte et de personnes prises en charge, reportez-vous à la section [Agir dans le guide d’utilisation](https://experienceleague.adobe.com/fr/docs/journey-optimizer-b2b/user/journeys/journey-nodes/action-nodes){target="_blank"}.
